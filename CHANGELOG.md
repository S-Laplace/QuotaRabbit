# Changelog

## [1.0.0] - 2026-11-09

Initial QuotaRabbit public release baseline.

- Monitor quotas, balances, refresh intervals, and account state across supported AI providers.
- Display usage history, Codex analytics, quota activity, and reset countdowns where data is available.
- Provide account management, configurable notifications, and resizable home-screen widgets.
- Support Korean, English, and Simplified Chinese interface resources, with light/dark themes.
- Preserve the original MIT license and copyright notice; see [LICENSE](LICENSE).

The public repository starts with a single 1.0.0 initial commit; pre-release commits are not included.
